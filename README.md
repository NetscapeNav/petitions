# Платформа петиций

Веб-приложение для создания и подписания петиций. Платформа позволяет объединять усилия для решения важных вопросов, обеспечивая прозрачность и защиту от накруток

## Ключевые возможности

* **Удобная авторизация:** Вход в один клик через официальный виджет Telegram
* **Верификация пользователей:** Подтверждение принадлежности к учебному заведению или региону через email
* **Создание инициатив:** Возможность подать петицию с привязкой к конкретной локации или для всех, а также прикреплять подтверждающие документы и файлы
* **Один голос = один человек:** Проверки на бэкенде гарантируют, что пользователь может подписать петицию только один раз, и только если его подтвержденная локация совпадает с локацией петиции
* **Telegram-уведомления:** Автор петиции может в один клик отправить важное обновление всем подписавшимся прямо в личные сообщения в Telegram
* **Красивые ссылки:** Система генерации ссылок с Open Graph разметкой. При отправке ссылки в мессенджеры автоматически подтягивается название конкретной петиции

## Стек технологий

**Frontend:**
* React 18 + TypeScript
* React Router (SPA маршрутизация)
* Кастомная система уведомлений (myAlert)

**Backend:**
* Python 3 + FastAPI
* MySQL (через `mysql-connector-python`)
* Авторизация на основе безопасных `HttpOnly Cookies`

## Установка и запуск

### 1. Подготовка базы данных
* Установите MySQL Server
* Создайте базу данных (схемы таблиц `users`, `petitions`, `signatures`)

### 2. Запуск FastAPI
1. Перейдите в папку бэкенда
2. Установите зависимости:
* ```pip install fastapi uvicorn mysql-connector-python requests```
* Настройте конфигурацию в файле `config.py`:
    *    Данные для подключения к MySQL
    *    Учетные данные SMTP-сервера для рассылки кодов верификации
    *    `TOKEN` вашего Telegram-бота и `admin_id`
*    Запустите сервер: `uvicorn main:app --reload --port 8000`
### 3. Запуск React
*    Перейдите в папку `src`
*    Убедитесь, что в файле `config.ts` указан правильный `API_URL` вашего бэкенда
*    Установите зависимости и запустите проект:
        ```
        npm install
        npm start
        ```

## Безопасность
В проекте реализованы методы по обеспечению безопасности:
*    Валидация токенов через БД
*    Строгая изоляция данных
*    HTML-escaping для защиты от XSS-атак
*    Безопасное сохранение загружаемых файлов со случайной генерацией имен и валидацией расширений
